# palindrome-analyzer

# Description
Python program that checks whether a string is a palindrome.

If the input is a palindrome, the program :
1. Creates a dictionary containing the word and its length.
2. Creates a list containing the individuals characters of the word.

# Features
- The program runs continuously until the user enters "q" to exit.
- Palindrome validation using string slicing.
- Dictionary creation.
- Character list generator.

# Example 
- Input : "radar"
- Output : 
 - Dictionary: {'radar': 5}  
 - Character list: ['r','a', 'd', 'a', 'r']
